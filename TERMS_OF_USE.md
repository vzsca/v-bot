v-bot includes potentially disruptive commands such as:

- `raid`
- `remove_raid`
- `dmall`
- `spam`

These commands are disabled by default.

If enabled, they must only be used in environments where you have the appropriate authorization and where their use is legitimate and permitted.

The project maintainers do not encourage using these features to disrupt, spam, or attack Discord servers or users.
