# v-bot Web Panel — Static Preview

This directory contains a frontend-only preview of the future web control panel.

- HTML/CSS/JS only.
- Sidebar navigation works locally with hash-based pages.
- Buttons and forms are visual placeholders only.
- No connection to `main.py`, `panel.py`, APIs, processes, files, authentication, or backend logic.
- The existing bot and CLI panel are intentionally untouched.

Open `index.html` directly in a browser to preview the interface.
